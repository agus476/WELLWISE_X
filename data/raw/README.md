# Datos originales

Los dos Excel de esta carpeta se conservan sin modificar. `manifest.json` registra sus tamaños y SHA-256 para comprobar su integridad. La fecha del inventario indica cuándo se registraron los archivos en el proyecto; no es una fecha de descarga de Equinor. La procedencia original detallada sigue pendiente de verificación.

Los notebooks leen estos archivos y analizan copias en memoria. No guardar aquí datos limpios, imputaciones, variables derivadas ni resultados. Antes de preparar un conjunto para modelos, definir por escrito cómo tratar fechas ausentes, días sin producción, unidades y pozos seleccionados.

Los archivos estuvieron antes en `data/bronze/`; Git conserva ese historial. El cambio de carpeta no modificó los Excel.
